# Code of Conduct

## Our standard

Be decent. This is a small, technical project — the rules are simple:

- **Be respectful** in issues, discussions and reviews. Critique code, not
  people.
- **Be honest.** Report bugs as you observed them; benchmarks and claims need
  evidence. Fabricated results are the one unforgivable sin here.
- **Assume competence and good faith.** Most problems are misunderstandings.

## Enforcement

Maintainers may remove comments, close discussions and block accounts that
violate this standard. Reports go to the maintainer via
[GitHub contact](https://github.com/litbitrim) or a private security report.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/);
in case of conflict, the short rules above win.
